---
name: Consistent section navigation
description: User requirement for matching Home buttons throughout Crypto Order Flow.
---
Use the same Home button on LSAR, Funding Rate and the other section pages.

**Why:** the user noticed that LSAR and Funding had different Home buttons and
explicitly requested that all pages use the same button.

**How to apply:** preserve the shared Home-button appearance and destination
when building additional order-flow sections, rather than introducing a
section-specific variant.
